## Хадгалсан бүтэц ба үлдээсэн текст

`t(mn, en)` болон bilingual object/tuple бүтцийг хадгалсан. Англи эхийг `scripts/check-english-copy.mjs`-ээр суурь commit-той харьцуулна. Энэ нь literal-уудын шалгалт; runtime тестийг орлохгүй. Шинээр хөрвүүлсэн hardcoded UI нь хоёр хэлний хувилбартай.

`scripts/audit-ui-copy.mjs` нь hardcoded JSX, attribute, Монгол текст доторх латин үгийг жагсаана. Брэнд, файлын формат, slug, decorative artwork болон ашиглагдахгүй `app/legacy-home.tsx`-ийн жишиг контентыг хөрвүүлээгүй. Хэрэглэгчийн бүтээл, үйлчилгээ, чат, үл мэдэгдэх enum fallback-ийг өөрчилдөггүй. `/beta` хуучин хаалттай beta гэсэн гарчгийг өнөөгийн open-beta төлөвтэй нийцүүлсэн.

## QA

Командууд: `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, `npm run build:preview`, `npx playwright test`, `node scripts/check-english-copy.mjs`.

Windows дээр браузерын тестийн localhost серверт bundled Python-ийн замтай, Git-д орохгүй `qa-local.config.mjs` хэрэглэсэн. CI нь repository-ийн анхны тохиргоог ашиглана.

Browser QA нь бодит auth/storage/realtime интеграцийн бүрэн баталгаа биш. Бодит хэрэглэгчийн захиалга үүсгэх, чат илгээх, админ эрх өөрчлөх туршилт хийгээгүй. Preview deployment ба CI-ийн эцсийн холбоос, үр дүнг PR-д тэмдэглэнэ.

### Локал үр дүн — 2026-10-26

- 240 unit/regression тест амжилттай; typecheck, lint, runtime build, static preview build амжилттай.
- Англи эхийн 1,611 literal өөрчлөгдөөгүй (`missing: []`).
- Эхний 84 browser тестээс 79 амжилттай. 4 нь хуучин Монгол текстийн selector-оос шалтгаалж унасан; шинэ текстэд нийцүүлсний дараа амжилттай. Мэдэгдлээс чат нээх 390 px тест нэг удаа унасан, өөрчлөлтгүй дахин ажиллуулахад амжилттай болсон.
- Нэмсэн 2 stress тестээр 320 px дээр урт, зайгүй нэр grid-ийг 1,394 px болгож тэлж байгааг илрүүлсэн. Мэргэжилтний картын `min-width` болон нэрийн мөр шилжилтийг зассаны дараа хоёулаа амжилттай. Нэрийг тайрах, өөрчлөх, хуудасны overflow-ийг нуух арга хэрэглээгүй.
- Нийт 86 browser case дахин шалгалтуудыг оролцуулан амжилттай болсон. CI нэг бүтэн run-аар дахин баталгаажуулна.
- Нэмсэн localization matrix: MN/EN × 320/390/768/1440 px; хоёр талын самбар, хэл солих, багцын үнэ, нэвтрэх алдаа, FAQ/footer; dark mobile ба урт нэр.
- Browser screenshot, trace нь `test-results*/`, `playwright-report/`-д үүснэ; Git-д орохгүй. CI artifact-аар хянах боломжтой.
